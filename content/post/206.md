## 题目概括

反转一个单链表并返回新的头节点。空链表应返回 `nullptr`。

## 核心思路

遍历链表时保存下一节点，再把当前节点的 `next` 指向已经反转好的前缀。`prev` 始终是反转后部分的头。

## 算法步骤

1. 初始化 `prev = nullptr`、`current = head`。
2. 保存 `current->next`。
3. 将 `current->next` 改为 `prev`。
4. 同步推进 `prev` 和 `current`，最后返回 `prev`。

## C++17 实现

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* current = head;

        while (current) {
            ListNode* next = current->next;
            current->next = prev;
            prev = current;
            current = next;
        }
        return prev;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 易错点

- 修改 `next` 前必须先保存后继节点，否则会丢失未处理部分。
- 新链表尾节点必须指向 `nullptr`，初始 `prev = nullptr` 正好保证这一点。

## 模板总结

链表原地反转的固定顺序是：保存后继、反转指针、推进前驱、推进当前节点。
