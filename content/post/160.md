## 🔹 题目

给定两个无环单链表，返回它们第一次相交的节点；如果不相交则返回 `nullptr`。相交比较的是节点地址，不是节点值。

## 🔹 思路

两个指针分别遍历 A、B，走到末尾后切换到另一条链表。它们都走过 `lenA + lenB` 后，长度差被抵消，最终在交点或 `nullptr` 相遇。

## 🔹 C++17

```cpp
class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        ListNode* a = headA;
        ListNode* b = headB;
        while (a != b) {
            a = a ? a->next : headB;
            b = b ? b->next : headA;
        }
        return a;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(m + n)`。
- 空间复杂度：`O(1)`。

## 🔹 易错点

- 必须比较指针地址，不能比较 `val`。
- 不相交时两个指针最终都会成为 `nullptr`，循环可以正常结束。
