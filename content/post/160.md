## 题目概括

给定两个无环单链表，返回它们第一次相交的节点；如果不相交则返回 `nullptr`。相交比较的是节点地址，不是节点值。

## 核心思路

两个指针分别遍历 A、B，走到末尾后切换到另一条链表。它们都走过 `lenA + lenB` 后，长度差被抵消，最终在交点或 `nullptr` 相遇。

## 算法步骤

1. 分别用 `a`、`b` 指向两条链表头。
2. 当两者不相等时各走一步；到末尾则切换到另一条链表头。
3. 返回两指针相遇的位置。

## C++17 实现

```cpp
class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        ListNode* a = headA;
        ListNode* b = headB;
        while (a != b) {
            a = a ? a->next : headB;
            b = b ? b->next : headA;
        }
        return a;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(m + n)`。
- 空间复杂度：`O(1)`。

## 易错点

- 必须比较指针地址，不能比较 `val`。
- 不相交时两个指针最终都会成为 `nullptr`，循环可以正常结束。

## 模板总结

两条链表存在长度差时，“走完自己的再走对方的”可以让两个指针经过相同总路程。
