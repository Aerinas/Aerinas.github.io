## 题目概括

给定字符串 `s`，求不包含重复字符的最长连续子串长度。空字符串的答案为 0。

## 核心思路

用左边界 `left` 和右边界 `right` 表示当前无重复窗口，并记录每个字符最近一次出现的位置。遇到重复字符时，左边界只能向右移动，不能回退。

## 算法步骤

1. 初始化 `left = 0`，用哈希表保存字符最后出现的下标。
2. 枚举右端点 `right`。
3. 如果当前字符在窗口内出现过，将 `left` 更新到上次位置的后一位。
4. 更新字符位置与窗口最大长度。

## C++17 实现

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        vector<int> last(256, -1);
        int left = 0;
        int answer = 0;

        for (int right = 0; right < static_cast<int>(s.size()); ++right) {
            unsigned char ch = static_cast<unsigned char>(s[right]);
            left = max(left, last[ch] + 1);
            last[ch] = right;
            answer = max(answer, right - left + 1);
        }
        return answer;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`，字符表大小固定。

## 易错点

- 左边界必须使用 `max(left, last[ch] + 1)`，否则可能回退。
- 更新答案时窗口长度为 `right - left + 1`。
- 使用字符作为数组下标时先转为 `unsigned char` 更稳妥。

## 模板总结

“最长且满足某条件的连续区间”常用可变长度滑动窗口；右端扩张，条件失效时移动左端恢复合法性。
