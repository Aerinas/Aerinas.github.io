## 🔹 题目

返回二叉树从根节点到最远叶节点的节点数量。空树深度为 0。

## 🔹 思路

一棵非空树的最大深度等于左右子树最大深度中的较大值加 1。递归函数直接返回当前子树的答案。

## 🔹 C++17

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        return 1 + max(maxDepth(root->left), maxDepth(root->right));
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(h)`，递归栈深度为树高。

## 🔹 易错点

- 深度按节点数计算，所以非空节点需要加 1。
- 极度退化的树会产生 `O(n)` 递归栈。
- 空树边界必须返回 0。
