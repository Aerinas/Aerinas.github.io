## 题目概括

每两个相邻节点交换一次，不能只交换节点值；若节点数为奇数，最后一个节点保持原位。

## 核心思路

`prev` 指向当前待交换节点对的前驱。设两个节点为 `first`、`second`，依次修改三条连接，再把 `prev` 移到交换后的尾节点。

## 算法步骤

1. 创建哑节点并初始化 `prev`。
2. 当后面至少有两个节点时取出 `first` 和 `second`。
3. 依次连接 `first->next`、`second->next` 和 `prev->next`。
4. 将 `prev` 移到 `first`，继续处理下一对。

## C++17 实现

```cpp
class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        ListNode dummy(0, head);
        ListNode* prev = &dummy;

        while (prev->next && prev->next->next) {
            ListNode* first = prev->next;
            ListNode* second = first->next;

            first->next = second->next;
            second->next = first;
            prev->next = second;

            prev = first;
        }
        return dummy.next;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 易错点

- 循环前要确认剩余节点至少有两个。
- 三次改链顺序需要保证后半段链表不会丢失。
- 交换后 `first` 成为这一对的尾节点，下一轮前驱应移动到它。

## 模板总结

局部反转链表时先明确“区间前驱、区间节点、区间后继”，再按不会丢链的顺序修改指针。
