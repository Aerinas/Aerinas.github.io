## 🔹 题目

每两个相邻节点交换一次，不能只交换节点值；若节点数为奇数，最后一个节点保持原位。

## 🔹 思路

`prev` 指向当前待交换节点对的前驱。设两个节点为 `first`、`second`，依次修改三条连接，再把 `prev` 移到交换后的尾节点。

## 🔹 C++17

```cpp
class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        ListNode dummy(0, head);
        ListNode* prev = &dummy;

        while (prev->next && prev->next->next) {
            ListNode* first = prev->next;
            ListNode* second = first->next;

            first->next = second->next;
            second->next = first;
            prev->next = second;

            prev = first;
        }
        return dummy.next;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 🔹 易错点

- 循环前要确认剩余节点至少有两个。
- 三次改链顺序需要保证后半段链表不会丢失。
- 交换后 `first` 成为这一对的尾节点，下一轮前驱应移动到它。
