## 🔹 题目

在升序数组中查找 `target`：存在时返回下标，不存在时返回它按顺序插入的位置，要求 `O(log n)`。

## 🔹 思路

- 本质是寻找第一个大于等于 `target` 的位置，也就是 `lower_bound`。
- 若 `nums[mid] < target`，答案只能在右侧，令 `left = mid + 1`。
- 否则当前值可能就是答案，继续向左收缩，令 `right = mid - 1`。
- 循环结束时，`left` 就是目标下标或插入位置。

## 🔹 C++17

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = static_cast<int>(nums.size()) - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return left;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(log n)`。
- 空间复杂度：`O(1)`。

## 🔹 易错点

- 循环使用闭区间 `[left, right]`，条件应为 `left <= right`。
- 最终返回 `left`，它可能等于 `nums.size()`，表示插入到数组末尾。
- 使用 `left + (right - left) / 2` 可以避免 `left + right` 溢出。
