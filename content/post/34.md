## 🔹 题目

在非递减数组中找到 `target` 第一次和最后一次出现的位置；不存在时返回 `[-1, -1]`，要求 `O(log n)`。

## 🔹 思路

- `lower_bound` 返回第一个大于等于 `target` 的位置，可作为左边界。
- 若该位置到达末尾或值不等于 `target`，说明目标不存在。
- `upper_bound` 返回第一个严格大于 `target` 的位置，向前一位就是右边界。

二者内部都是二分查找，关键比较分别是：

```cpp
// lower_bound：第一个 >= target
if (nums[mid] < target) left = mid + 1;
else right = mid;

// upper_bound：第一个 > target
if (nums[mid] <= target) left = mid + 1;
else right = mid;
```

## 🔹 C++17

```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        auto first = lower_bound(nums.begin(), nums.end(), target);
        if (first == nums.end() || *first != target) {
            return {-1, -1};
        }

        auto last = upper_bound(first, nums.end(), target);
        return {
            static_cast<int>(first - nums.begin()),
            static_cast<int>(last - nums.begin()) - 1
        };
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(log n)`。
- 空间复杂度：`O(1)`。

## 🔹 易错点

- 解引用 `first` 前，必须先判断 `first != nums.end()`。
- `upper_bound` 指向右边界的下一位，因此结果需要减一。
- 空数组会直接进入“不存在”的分支，不需要单独处理。
