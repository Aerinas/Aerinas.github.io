## 🔹 题目

将二叉树中每个节点的左右子树交换，返回翻转后的根节点。空树保持为空。

## 🔹 思路

翻转整棵树等价于交换当前节点的左右孩子，再递归翻转交换后的两个子树。每个节点只处理一次。

## 🔹 C++17

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (!root) return nullptr;

        swap(root->left, root->right);
        invertTree(root->left);
        invertTree(root->right);
        return root;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(h)`。

## 🔹 易错点

- 交换后递归处理的是新的左右子树。
- 题目允许原地修改，不需要创建新树。
- 空树必须安全返回。
