## 题目概括

将二叉树中每个节点的左右子树交换，返回翻转后的根节点。空树保持为空。

## 核心思路

翻转整棵树等价于交换当前节点的左右孩子，再递归翻转交换后的两个子树。每个节点只处理一次。

## 算法步骤

1. 当前节点为空时返回 `nullptr`。
2. 交换当前节点的 `left` 和 `right`。
3. 递归翻转新的左子树和右子树。
4. 返回当前根节点。

## C++17 实现

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (!root) return nullptr;

        swap(root->left, root->right);
        invertTree(root->left);
        invertTree(root->right);
        return root;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(h)`。

## 易错点

- 交换后递归处理的是新的左右子树。
- 题目允许原地修改，不需要创建新树。
- 空树必须安全返回。

## 模板总结

对树的每个节点执行相同局部操作时，先确定操作与递归的先后顺序，再遍历所有子树。
