## 题目概括

删除单链表倒数第 `n` 个节点并返回头节点。题目保证 `n` 合法。

## 核心思路

让 `fast` 比 `slow` 提前 `n + 1` 步，使 `fast` 到达末尾时，`slow` 正好停在待删除节点的前驱。哑节点让删除头节点也使用相同逻辑。

## 算法步骤

1. 创建指向 `head` 的哑节点，快慢指针都从哑节点出发。
2. 快指针先走 `n + 1` 步。
3. 快慢指针同步前进直到快指针为空。
4. 跳过 `slow->next` 并返回 `dummy.next`。

## C++17 实现

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);
        ListNode* fast = &dummy;
        ListNode* slow = &dummy;

        for (int i = 0; i <= n; ++i) {
            if (!fast) return head;
            fast = fast->next;
        }
        while (fast) {
            fast = fast->next;
            slow = slow->next;
        }

        ListNode* removed = slow->next;
        slow->next = removed->next;
        delete removed;
        return dummy.next;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(L)`。
- 空间复杂度：`O(1)`。

## 易错点

- 为定位前驱，快指针需要比慢指针多走 `n + 1` 步。
- 删除头节点时必须借助哑节点。
- LeetCode 保证 `n` 合法；防御性判断用于避免非法输入解引用空指针。

## 模板总结

查找倒数第 `n` 个位置可使用固定间距双指针；涉及删除时，让慢指针最终停在目标节点前驱。
