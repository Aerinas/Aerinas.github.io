## 🔹 题目

原地把所有零移动到数组末尾，同时保持非零元素的相对顺序。

## 🔹 思路

- `lastNonZero` 表示下一个非零元素应该写入的位置。
- 第一遍按原顺序覆盖非零元素。
- 第二遍把剩余区间全部填成零。

## 🔹 C++17

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int lastNonZero = 0;
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] != 0) {
                nums[lastNonZero++] = nums[i];
            }
        }
        for (int i = lastNonZero; i < nums.size(); i++) {
            nums[i] = 0;
        }
    }
};
```

## 🔹 复杂度

- 时间：`O(n)`
- 空间：`O(1)`

## 🔹 易错点

- 必须原地修改，不能另建结果数组。
- 覆盖非零元素后别忘了把尾部补零。
