## 283. Move Zeroes

### 🔹 题目描述
给定一个数组 `nums`，编写一个函数将所有 **0 移动到数组的末尾**，同时保持非零元素的相对顺序。  
必须在原地完成，不能拷贝额外数组。

### 🔹 解题思路
- **思路 1（朴素法）**：遇到 0 时往后找第一个非零数进行交换，最坏情况接近 O(n²)。  
- **思路 2（双指针 O(n)）**：  
  - 用 `lastNonZero` 指针表示下一个应该放非零数的位置。  
  - 遍历数组，如果当前数非零，就把它放到 `lastNonZero` 位置，`lastNonZero++`。  
  - 遍历完成后，把 `[lastNonZero, n)` 填 0。  

### 🔹 关键点
- **保持相对顺序**：用“覆盖 + 最后填 0”的方式，而不是单纯交换。  
- **空间限制**：O(1)，只能原地修改。  
- **两段操作**：第一段搬运非零，第二段补零。

### 🔹 C++ 实现要点
```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int lastNonZero = 0;
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] != 0) {
                nums[lastNonZero++] = nums[i];
            }
        }
        for (int i = lastNonZero; i < nums.size(); i++) {
            nums[i] = 0;
        }
    }
};
