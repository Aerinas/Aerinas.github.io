## 🔹 题目

矩阵每行递增，并且下一行首元素大于上一行末元素。判断 `target` 是否存在，要求 `O(log(m × n))`。

## 🔹 思路与 C++ 语法

先在所有行的首元素中定位候选行，再在这一行内执行普通二分查找。

### 1. `upper_bound` 与 Lambda 比较器

```cpp
auto row = upper_bound(
    matrix.begin(),
    matrix.end(),
    target,
    [](int value, const vector<int>& currentRow) {
        return value < currentRow[0];
    }
);
```

四参数形式为：

```cpp
upper_bound(first, last, value, comp)
```

它返回第一个满足“`value` 应排在当前元素之前”的位置。这里区间元素是 `vector<int>`，搜索值却是 `int`，所以需要自定义比较器：

```cpp
[](int value, const vector<int>& currentRow) {
    return value < currentRow[0];
}
```

这段 Lambda 可以拆成：

- `[]`：不捕获外部变量；
- 参数一 `value`：传入的 `target`；
- 参数二 `currentRow`：当前参与比较的一整行；
- 返回值：判断 `target < currentRow[0]`。

因此，`upper_bound` 找到的是**第一行首元素严格大于 `target` 的位置**。向前移动一行后，就是最后一行首元素小于等于 `target` 的候选行。

如果结果等于 `matrix.begin()`，说明 `target` 比第一行首元素还小，不能执行 `--row`。

### 2. `binary_search`

```cpp
binary_search(row->begin(), row->end(), target)
```

`binary_search` 在有序区间 `[first, last)` 中查找目标值：

- 找到返回 `true`；
- 找不到返回 `false`；
- 它只判断是否存在，不返回具体位置。

这里的 `row` 是矩阵的行迭代器，因此：

- `row->begin()` 是候选行的起点；
- `row->end()` 是候选行的尾后位置。

## 🔹 C++17

```cpp
class Solution {
public:
    bool searchMatrix(const vector<vector<int>>& matrix, int target) {
        if (matrix.empty() || matrix[0].empty()) {
            return false;
        }

        auto row = upper_bound(
            matrix.begin(),
            matrix.end(),
            target,
            [](int value, const vector<int>& currentRow) {
                return value < currentRow[0];
            }
        );

        if (row == matrix.begin()) {
            return false;
        }

        --row;
        return binary_search(row->begin(), row->end(), target);
    }
};
```

## 🔹 复杂度

- 定位候选行：`O(log m)`
- 行内查找：`O(log n)`
- 总时间：`O(log m + log n)`，等价于题目要求的 `O(log(m × n))`
- 额外空间：`O(1)`

## 🔹 易错点

- `upper_bound` 的比较器参数顺序是“搜索值、区间元素”，不能写反。
- `--row` 前必须判断 `row != matrix.begin()`。
- `binary_search` 要求候选行已经按升序排列。
- 调用 Lambda 前要排除空矩阵和空行，否则 `currentRow[0]` 会越界。
