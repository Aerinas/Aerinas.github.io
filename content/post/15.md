## 15. 3Sum

### 🔹 题目描述
给定整数数组 `nums`，找出所有和为 0 的**不重复**三元组 `[a,b,c]`，要求：`a + b + c = 0`。

### 🔹 解题思路
- 先对数组排序，外层固定第一个数 `nums[i]`。
- 在区间 `[i+1, n-1]` 用**左右双指针**（`j=i+1, k=n-1`）寻找 `nums[j] + nums[k] = -nums[i]`。
- 根据三数之和 `sum` 与 0 的比较移动指针：
  - `sum < 0` → `j++`
  - `sum > 0` → `k--`
  - `sum == 0` → 记录解；随后 **`j++` 与 `k--`**，并**跳过重复值**。

### 🔹 关键点
- **去重 1（外层）**：若 `i>0 && nums[i]==nums[i-1]`，直接跳过，避免相同首元素重复计算。
- **去重 2（内层）**：命中一组解后，先同时 `++j`、`--k`，再在 `j<k` 条件下：
  - 跳过与前一位置相同的 `j`：`while (j<k && nums[j]==nums[j-1]) ++j;`
  - 跳过与后一位置相同的 `k`：`while (j<k && nums[k]==nums[k+1]) --k;`
- **剪枝**：排序后若 `nums[i] > 0`，后续不可能再有解，可 `break`。
- **越界与顺序**：所有“跳重”判断都置于 `j<k` 保护下，且顺序为**先移动，再跳重**，避免遗漏和越界。

### 🔹 C++ 实现要点
- 使用 `std::sort` 排序；双指针在同一数组上原地移动，空间友好。
- 命中一组解后的顺序应为：
  ```cpp
  answer.push_back({nums[i], nums[j], nums[k]});
  ++j; --k;
  while (j < k && nums[j] == nums[j-1]) ++j;
  while (j < k && nums[k] == nums[k+1]) --k;
  ```

## 算法步骤

1. 对数组排序。
2. 枚举三元组第一个元素并跳过重复值。
3. 在右侧区间使用左右双指针，根据三数之和移动边界。
4. 找到答案后同时移动两端并跳过重复值。

## C++17 实现

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> answer;
        sort(nums.begin(), nums.end());

        for (int i = 0; i + 2 < static_cast<int>(nums.size()); ++i) {
            if (nums[i] > 0) break;
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int left = i + 1;
            int right = static_cast<int>(nums.size()) - 1;
            while (left < right) {
                long long sum = static_cast<long long>(nums[i]) +
                                nums[left] + nums[right];
                if (sum < 0) {
                    ++left;
                } else if (sum > 0) {
                    --right;
                } else {
                    answer.push_back({nums[i], nums[left], nums[right]});
                    ++left;
                    --right;
                    while (left < right && nums[left] == nums[left - 1]) ++left;
                    while (left < right && nums[right] == nums[right + 1]) --right;
                }
            }
        }
        return answer;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n²)`。
- 空间复杂度：`O(log n)`，取决于排序实现的递归栈，不计答案。

## 易错点

- 外层和双指针命中后都需要去重。
- 跳过内部重复值前必须先移动指针，并用 `left < right` 防止越界。
- 使用 `long long` 计算三数之和可避免整数溢出。

## 模板总结

有序数组的三数之和可降维为“枚举一个数 + 双指针求两数之和”，去重是正确性的核心组成部分。
