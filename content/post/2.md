## 🔹 题目

两个链表按低位到高位保存非负整数的每一位，返回它们相加后的同格式链表。

## 🔹 思路

同步遍历两个链表，逐位计算 `x + y + carry`。当前结果位是和对 10 取模，新的进位是整除 10。

## 🔹 C++17

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy;
        ListNode* tail = &dummy;
        int carry = 0;

        while (l1 || l2 || carry) {
            int x = l1 ? l1->val : 0;
            int y = l2 ? l2->val : 0;
            int sum = x + y + carry;

            carry = sum / 10;
            tail->next = new ListNode(sum % 10);
            tail = tail->next;

            if (l1) l1 = l1->next;
            if (l2) l2 = l2->next;
        }
        return dummy.next;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(max(m, n))`。
- 空间复杂度：`O(max(m, n))`，用于返回的新链表。

## 🔹 易错点

- 循环条件必须包含最后可能剩余的 `carry`。
- 两条链表长度可以不同，缺失位应视为 0。
- 数字是逆序存储，不需要先反转链表。
