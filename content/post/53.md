## 🔹 题目

给定整数数组，寻找和最大的连续非空子数组并返回其元素和。

## 🔹 思路

`current` 表示必须以当前位置结尾的最大子数组和。对于当前数，要么接在前一段后面，要么从当前数重新开始。

## 🔹 C++17

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        if (nums.empty()) return 0;

        int current = nums[0];
        int answer = nums[0];
        for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
            current = max(nums[i], current + nums[i]);
            answer = max(answer, current);
        }
        return answer;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 🔹 易错点

- 子数组必须非空，不能把初值设为 0，否则全负数组会出错。
- `current` 与 `answer` 的含义不同：一个必须以当前位置结尾，一个是全局最优。
