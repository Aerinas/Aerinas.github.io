## 题目概括

判断一棵二叉树是否关于根节点的中心轴镜像对称。空树视为对称。

## 核心思路

镜像位置的两个节点必须值相等，并且左节点的左子树与右节点的右子树互为镜像，左节点的右子树与右节点的左子树互为镜像。

## 算法步骤

1. 编写辅助函数比较两个镜像位置节点。
2. 两者都为空返回 `true`，只有一个为空返回 `false`。
3. 节点值不同返回 `false`。
4. 交叉递归比较外侧子树和内侧子树。

## C++17 实现

```cpp
class Solution {
    bool mirror(TreeNode* left, TreeNode* right) {
        if (!left || !right) return left == right;
        return left->val == right->val &&
               mirror(left->left, right->right) &&
               mirror(left->right, right->left);
    }

public:
    bool isSymmetric(TreeNode* root) {
        return !root || mirror(root->left, root->right);
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(h)`。

## 易错点

- 比较方向必须交叉：左左对右右，左右对右左。
- 两个空节点是对称的，只有一个为空则不对称。
- 不能只比较同一层的节点值集合，还必须比较结构位置。

## 模板总结

判断两棵树是否满足对应关系时，用双参数递归同时推进两个节点，并明确它们的配对方向。
