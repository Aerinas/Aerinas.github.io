## 🔹 题目

如果链表存在环，返回环的入口节点；否则返回 `nullptr`。

## 🔹 思路

快慢指针第一次在环内相遇后，把其中一个指针放回链表头。两个指针再以相同速度前进，它们下一次相遇的位置就是环入口。

## 🔹 C++17

```cpp
class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;

        do {
            if (!fast || !fast->next) return nullptr;
            slow = slow->next;
            fast = fast->next->next;
        } while (slow != fast);

        slow = head;
        while (slow != fast) {
            slow = slow->next;
            fast = fast->next;
        }
        return slow;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 🔹 易错点

- 空链表和单节点无环链表必须安全返回。
- 第一阶段相遇后，两指针都改为每次走一步。
- 返回的是入口节点指针，不是入口下标。
