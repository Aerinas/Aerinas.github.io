## 题目概括

如果链表存在环，返回环的入口节点；否则返回 `nullptr`。

## 核心思路

快慢指针第一次在环内相遇后，把其中一个指针放回链表头。两个指针再以相同速度前进，它们下一次相遇的位置就是环入口。

## 算法步骤

1. 使用 Floyd 快慢指针寻找第一次相遇点。
2. 若快指针到达末尾，说明无环。
3. 将慢指针重置到 `head`，快指针留在相遇点。
4. 两者每次各走一步，相遇时返回该节点。

## C++17 实现

```cpp
class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;

        do {
            if (!fast || !fast->next) return nullptr;
            slow = slow->next;
            fast = fast->next->next;
        } while (slow != fast);

        slow = head;
        while (slow != fast) {
            slow = slow->next;
            fast = fast->next;
        }
        return slow;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 易错点

- 空链表和单节点无环链表必须安全返回。
- 第一阶段相遇后，两指针都改为每次走一步。
- 返回的是入口节点指针，不是入口下标。

## 模板总结

环入口定位分两阶段：先用速度差制造相遇，再用头到入口距离与相遇点到入口距离的等价关系定位入口。
