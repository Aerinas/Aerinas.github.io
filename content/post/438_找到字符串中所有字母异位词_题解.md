## 🔹 题目

找出字符串 `s` 中所有与 `p` 互为字母异位词的子串起点。

## 🔹 思路

- 窗口长度固定为 `p.size()`。
- 分别维护 `p` 和当前窗口的 26 个小写字母频次。
- 窗口到达固定长度后，频次数组相等就记录起点。

## 🔹 C++17

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> ans;
        if (s.size() < p.size()) return ans;

        vector<int> cntP(26, 0), cntW(26, 0);

        for (char c : p)
            cntP[c - 'a']++;

        int window = p.size();

        for (int i = 0; i < s.size(); ++i) {
            cntW[s[i] - 'a']++;

            if (i >= window)
                cntW[s[i - window] - 'a']--;

            if (i >= window - 1 && cntW == cntP)
                ans.push_back(i - window + 1);
        }
        return ans;
    }
};
```

## 🔹 复杂度

- 时间：`O(n)`，比较长度固定为 26 的数组
- 空间：`O(1)`

## 🔹 易错点

- 右端加入字符后，要及时移除超出窗口的左端字符。
- `s.size() < p.size()` 时应直接返回。
