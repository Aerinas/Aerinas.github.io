## 一、题目描述（Problem Description）

给定两个字符串 **s** 和 **p**，找出 **s** 中所有 **p** 的 **字母异位词（Anagram）** 的子串，返回这些子串的**起始索引**。

- 不要求输出顺序
- 子串长度必须等于 `p.length()`

**字母异位词（Anagram）定义**：
> 若两个字符串包含的字符种类相同，且每个字符出现次数相同，只是顺序不同，则互为字母异位词。

---

## 二、示例（Examples）

### 示例 1

```text
输入: s = "cbaebabacd", p = "abc"
输出: [0, 6]
```

解释：
- s[0..2] = "cba" 是 "abc" 的异位词
- s[6..8] = "bac" 是 "abc" 的异位词

### 示例 2

```text
输入: s = "abab", p = "ab"
输出: [0, 1, 2]
```

## 三、核心思路（Core Idea）

### 中文

这是一个**经典的滑动窗口（Sliding Window）问题**。

- 固定窗口长度 = `|p|`
- 在字符串 `s` 上从左向右滑动窗口
- 维护窗口内字符出现次数
- 当窗口内字符计数 == `p` 的字符计数时，说明找到了一个异位词

### English (Simple)

This is a **sliding window problem**:

- Window size is fixed to `len(p)`
- Slide the window on string `s`
- Maintain character frequency
- If frequencies match `p`, record the start index

---

## 四、为什么使用「下标 + 数组」而不是迭代器 / 指针？

- `std::string` 支持随机访问（`operator[]`）
- 用下标表示窗口左右边界最直观（`i - window + 1`）
- 避免 iterator 同步移动带来的复杂度
- 编译器会将下标访问优化为指针操作，**性能无损**

👉 在滑动窗口问题中：**下标是最清晰、最安全的选择**。

---

## 五、算法步骤（Algorithm Steps）

1. 若 `s.length() < p.length()`，直接返回空结果
2. 用长度为 26 的数组 `cntP` 统计 `p` 的字符频率
3. 用另一个数组 `cntW` 维护当前窗口的字符频率
4. 遍历 `s`：
   - 加入当前字符 `s[i]`
   - 若窗口超过长度 `|p|`，移除最左字符
   - 当窗口大小正好等于 `|p|`，比较 `cntW` 和 `cntP`
5. 若相等，记录起始下标

---

## 六、正确性说明（Correctness Proof）

- 滑动窗口保证：
  - 所有长度为 `|p|` 的子串都会被检查一次
- 字符频率数组完全刻画了一个字符串的“多重集合”特性
- 当且仅当两个频率数组相等时，两个字符串互为异位词

因此算法不会遗漏或误判任何解。

---

## 七、时间与空间复杂度（Complexity Analysis）

- **时间复杂度**：
  - O(n × 26) ≈ O(n)
- **空间复杂度**：
  - O(26 × 2) ≈ O(1)

其中 `n = s.length()`。

## 八、C++ 实现（C++ Implementation）

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> ans;
        if (s.size() < p.size()) return ans;

        vector<int> cntP(26, 0), cntW(26, 0);

        for (char c : p)
            cntP[c - 'a']++;

        int window = p.size();

        for (int i = 0; i < s.size(); ++i) {
            // add right character
            cntW[s[i] - 'a']++;

            // remove left character if window too large
            if (i >= window)
                cntW[s[i - window] - 'a']--;

            // check anagram
            if (i >= window - 1 && cntW == cntP)
                ans.push_back(i - window + 1);
        }
        return ans;
    }
};
```

## 九、常见错误（Common Pitfalls）

1. 忘记在窗口右移时**删除左侧字符**
2. 使用 `map` 导致常数过大
3. 在 `s.length() < p.length()` 时仍进入循环
4. 窗口大小判断写成 `>` 或 `<` 导致 off-by-one 错误

## 十、总结（Summary）

- 本题是**固定长度滑动窗口 + 计数数组**的典型模板题
- C++ 中使用 **下标访问 string** 是最清晰、最工程化的写法
- 熟练后可直接迁移到其他 Anagram / Frequency 类问题
