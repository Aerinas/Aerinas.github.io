## 128. Longest Consecutive Sequence

### 🔹 题目描述
给定一个未排序的整数数组，找出其中最长的连续元素序列的长度。要求算法时间复杂度为 O(n)。

### 🔹 解题思路
- **思路 1（有序集合 / map）：**  
  将所有元素放入 `map` 或 `set`，自动排序去重，再扫描判断是否连续。  
  - 复杂度：O(n log n)（插入有序结构）。
- **思路 2（哈希集合 O(n)）：**  
  - 使用 `unordered_set` 存储所有元素，支持 O(1) 平均查找。  
  - 遍历集合，每个数只在它是“序列起点”（即 `num-1` 不存在）时，才向右扩展统计长度。  
  - 保持全局最大值。

### 🔹 关键点
- **起点判断**：只从“左邻居不存在”的数开始扩展，避免重复计算。  
- **集合存储**：`unordered_set` 既去重又支持 O(1) 查找。  
- **收尾处理**：每段连续区间结束时更新最大值。

### 🔹 C++ 实现要点
- `unordered_set<int> st(nums.begin(), nums.end());` 直接构建哈希集合。  
- 遍历时用 `st.count(x)` 判断元素是否存在。  
- 变量命名：`curr` 表示当前数字，`len` 表示当前连续段长度。  
- 时间复杂度保证 O(n)：每个元素最多访问两次。

### 🔹 复杂度分析
- **时间复杂度**：O(n)（均摊，哈希查找为 O(1)）  
- **空间复杂度**：O(n)（存储哈希集合）

### 🔹 总结
- 使用 `map/set` 可以解，但复杂度为 O(n log n)。  
- 使用 `unordered_set` 并配合“起点扩展”技巧，能达到 O(n)，符合题意要求。  
- 核心思想是 **避免重复遍历**：每个连续序列只会从起点被遍历一次。

## 算法步骤

1. 把所有元素加入哈希集合并自动去重。
2. 只对不存在前驱 `value - 1` 的元素启动扩展。
3. 不断查询后继并统计当前序列长度。
4. 更新全局最长长度。

## C++17 实现

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> values(nums.begin(), nums.end());
        int answer = 0;

        for (int value : values) {
            if (value != INT_MIN && values.count(value - 1)) continue;

            int length = 1;
            int current = value;
            while (current != INT_MAX && values.count(current + 1)) {
                ++current;
                ++length;
            }
            answer = max(answer, length);
        }
        return answer;
    }
};
```

## 易错点

- 必须只从序列起点扩展，否则最坏会重复扫描成 `O(n²)`。
- 哈希集合用于去重，重复元素不应增加序列长度。
- 对 `INT_MIN - 1` 和 `INT_MAX + 1` 做保护，避免有符号整数溢出。

## 模板总结

哈希集合中的连续段应从“没有前驱”的端点开始一次性扩展，从而把重复工作降到线性规模。
