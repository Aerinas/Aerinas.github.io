## 🔹 题目

在未排序数组中求最长连续整数序列的长度，要求平均 `O(n)` 时间。

## 🔹 思路

- 把所有数字放入哈希集合，完成去重和常数时间查询。
- 只有当 `value - 1` 不存在时，`value` 才是一个序列的起点。
- 从起点不断查询下一个整数，更新最大长度。

## 🔹 C++17

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> values(nums.begin(), nums.end());
        int answer = 0;

        for (int value : values) {
            if (value != INT_MIN && values.count(value - 1)) continue;

            int current = value;
            int length = 1;
            while (current != INT_MAX && values.count(current + 1)) {
                ++current;
                ++length;
            }
            answer = max(answer, length);
        }
        return answer;
    }
};
```

## 🔹 复杂度

- 时间：平均 `O(n)`
- 空间：`O(n)`

## 🔹 易错点

- 不能从每个元素重复向后扫描，否则会退化为 `O(n²)`。
- 计算相邻值时要注意 `INT_MIN` 和 `INT_MAX` 溢出。
