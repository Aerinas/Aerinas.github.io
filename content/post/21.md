## 题目概括

将两个非递减链表合并为一个非递减链表，并复用原有节点。

## 核心思路

用 `tail` 指向结果链表末尾，每次从两个当前节点中选择较小者接入。哑节点统一处理头节点为空和首次插入的情况。

## 算法步骤

1. 创建哑节点并让 `tail` 指向它。
2. 两条链表都非空时，选择较小节点接到 `tail` 后。
3. 推进被选择的链表和 `tail`。
4. 将剩余链表整体接到结果末尾。

## C++17 实现

```cpp
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode dummy;
        ListNode* tail = &dummy;

        while (list1 && list2) {
            if (list1->val <= list2->val) {
                tail->next = list1;
                list1 = list1->next;
            } else {
                tail->next = list2;
                list2 = list2->next;
            }
            tail = tail->next;
        }
        tail->next = list1 ? list1 : list2;
        return dummy.next;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(m + n)`。
- 空间复杂度：`O(1)`。

## 易错点

- 循环结束后要连接未遍历完的链表。
- 哑节点在栈上即可，返回 `dummy.next`，不能返回局部哑节点地址。

## 模板总结

多个链表的头部需要反复比较或修改时，哑节点能消除“结果链表还没有头”的特殊分支。
