## 🔹 题目

将两个非递减链表合并为一个非递减链表，并复用原有节点。

## 🔹 思路

用 `tail` 指向结果链表末尾，每次从两个当前节点中选择较小者接入。哑节点统一处理头节点为空和首次插入的情况。

## 🔹 C++17

```cpp
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode dummy;
        ListNode* tail = &dummy;

        while (list1 && list2) {
            if (list1->val <= list2->val) {
                tail->next = list1;
                list1 = list1->next;
            } else {
                tail->next = list2;
                list2 = list2->next;
            }
            tail = tail->next;
        }
        tail->next = list1 ? list1 : list2;
        return dummy.next;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(m + n)`。
- 空间复杂度：`O(1)`。

## 🔹 易错点

- 循环结束后要连接未遍历完的链表。
- 哑节点在栈上即可，返回 `dummy.next`，不能返回局部哑节点地址。
