## 题目概括

按照“左子树、根节点、右子树”的顺序返回二叉树节点值。空树返回空数组。

## 核心思路

递归过程可以用栈显式模拟：持续沿左链压栈；没有左节点时弹出栈顶访问，再转向其右子树。

## 算法步骤

1. 初始化当前节点 `current = root` 和空栈。
2. 沿左子节点不断压栈。
3. 弹出栈顶并记录节点值。
4. 转向该节点右子树，重复直到当前节点和栈都为空。

## C++17 实现

```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> answer;
        stack<TreeNode*> nodes;
        TreeNode* current = root;

        while (current || !nodes.empty()) {
            while (current) {
                nodes.push(current);
                current = current->left;
            }
            current = nodes.top();
            nodes.pop();
            answer.push_back(current->val);
            current = current->right;
        }
        return answer;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(h)`，`h` 为树高。

## 易错点

- 外层循环条件必须是“当前节点存在或栈非空”。
- 节点出栈后先访问，再进入右子树。
- 空树无需特殊分支，循环自然不会执行。

## 模板总结

二叉树迭代中序遍历模板是：左链压栈、弹栈访问、转向右树。
