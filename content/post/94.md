## 🔹 题目

按照“左子树、根节点、右子树”的顺序返回二叉树节点值。空树返回空数组。

## 🔹 思路

递归过程可以用栈显式模拟：持续沿左链压栈；没有左节点时弹出栈顶访问，再转向其右子树。

## 🔹 C++17

```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> answer;
        stack<TreeNode*> nodes;
        TreeNode* current = root;

        while (current || !nodes.empty()) {
            while (current) {
                nodes.push(current);
                current = current->left;
            }
            current = nodes.top();
            nodes.pop();
            answer.push_back(current->val);
            current = current->right;
        }
        return answer;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(h)`，`h` 为树高。

## 🔹 易错点

- 外层循环条件必须是“当前节点存在或栈非空”。
- 节点出栈后先访问，再进入右子树。
- 空树无需特殊分支，循环自然不会执行。
