## 🔹 题目

深拷贝一条链表。每个节点除 `next` 外还有可指向任意节点或空的 `random` 指针。

## 🔹 思路

把每个复制节点插到原节点后面，借助相邻关系代替显式哈希表。这样原节点 `node` 的副本就是 `node->next`，随机指针也能通过 `node->random->next` 找到对应副本。

## 🔹 C++17

```cpp
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (!head) return nullptr;

        for (Node* node = head; node; node = node->next->next) {
            Node* copy = new Node(node->val);
            copy->next = node->next;
            node->next = copy;
        }

        for (Node* node = head; node; node = node->next->next) {
            node->next->random = node->random ? node->random->next : nullptr;
        }

        Node* copyHead = head->next;
        for (Node* node = head; node;) {
            Node* copy = node->next;
            node->next = copy->next;
            copy->next = copy->next ? copy->next->next : nullptr;
            node = node->next;
        }
        return copyHead;
    }
};
```

## 🔹 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)` 额外空间，不计返回链表。

## 🔹 易错点

- 空链表必须直接返回 `nullptr`。
- 设置 `random` 时要判断原随机指针是否为空。
- 拆分时既要恢复原链表，也要正确连接复制链表。
