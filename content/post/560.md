## 题目概括

给定整数数组 `nums` 和整数 `k`，统计元素和等于 `k` 的连续非空子数组数量。数组包含负数，不能直接使用普通滑动窗口。

## 核心思路

若当前位置前缀和为 `prefix`，此前存在前缀和 `prefix - k`，两者之间的子数组和就是 `k`。哈希表记录每种前缀和出现的次数。

## 算法步骤

1. 令空前缀和 `0` 出现一次。
2. 依次累加得到当前前缀和 `prefix`。
3. 将 `prefix - k` 的出现次数加入答案。
4. 再把当前 `prefix` 的次数加一。

## C++17 实现

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<long long, int> count{{0, 1}};
        long long prefix = 0;
        int answer = 0;

        for (int value : nums) {
            prefix += value;
            auto it = count.find(prefix - k);
            if (it != count.end()) answer += it->second;
            ++count[prefix];
        }
        return answer;
    }
};
```

## 复杂度分析

- 时间复杂度：平均 `O(n)`。
- 空间复杂度：`O(n)`。

## 易错点

- 必须预置 `count[0] = 1`，否则会漏掉从下标 0 开始的答案。
- 先查询再记录当前前缀和，避免错误计入空区间。
- 存在负数时窗口和不具单调性，滑动窗口不适用。

## 模板总结

连续区间和满足 `sum(l..r) = k` 时，可转化为两个前缀和之差：`prefix[r] - prefix[l-1] = k`。
