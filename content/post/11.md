## 11. Container With Most Water

### 🔹 题目描述
给定数组 `height`，第 i 根柱子高度为 `height[i]`，与 j 根柱子能装水的面积为 `min(height[i], height[j]) * (j - i)`。求最大装水面积。

### 🔹 解题思路
- **双指针夹逼**：左指针 `l=0`、右指针 `r=n-1`。
- 每轮计算当前面积，并更新答案。
- 始终移动**较短板**那一侧（若相等随便动一侧）：  
  - 移动较短板才有机会使 `min(h_left, h_right)` 变大；移动较长板只会让宽度变小且短板不变，面积不可能增大。

### 🔹 关键点
- 循环条件：`l < r`。
- 每轮只移动一个指针（短板侧）。
- 不需要排序，保持原下标的线性扫描即可。

### 🔹 C++ 实现要点
- 指针初始化：`int left = 0, right = height.size() - 1;`
- 面积更新：`area = min(height[left], height[right]) * (right - left)`
- 更新答案后，移动较短板：  
  ```cpp
  if (height[left] <= height[right]) ++left;
  else --right;
  ```

## 算法步骤

1. 左右指针分别指向数组两端。
2. 计算当前两条边能形成的面积并更新答案。
3. 移动高度较小的一侧，因为保留短板无法得到更大面积。
4. 重复直到左右指针相遇。

## C++17 实现

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        if (height.size() < 2) return 0;

        int left = 0;
        int right = static_cast<int>(height.size()) - 1;
        int answer = 0;
        while (left < right) {
            int area = min(height[left], height[right]) * (right - left);
            answer = max(answer, area);
            if (height[left] <= height[right]) {
                ++left;
            } else {
                --right;
            }
        }
        return answer;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 易错点

- 面积宽度是下标差 `right - left`。
- 每轮应移动短板，移动长板不可能弥补宽度损失。
- 少于两个元素时无法形成容器。

## 模板总结

相向双指针的贪心依据必须明确：每轮排除一个不可能产生更优解的边界。
