## 🔹 题目

选择两条竖线作为容器边界，求它们与横轴能围成的最大面积。

## 🔹 思路

- 左右指针从数组两端开始，当前面积为短板高度乘宽度。
- 宽度每轮都会缩小，只有移动短板才可能提高有效高度。
- 计算面积后移动较短的一侧，直到指针相遇。

## 🔹 C++17

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        if (height.size() < 2) return 0;
        int left = 0;
        int right = static_cast<int>(height.size()) - 1;
        int answer = 0;

        while (left < right) {
            int area = min(height[left], height[right]) * (right - left);
            answer = max(answer, area);
            if (height[left] <= height[right]) ++left;
            else --right;
        }
        return answer;
    }
};
```

## 🔹 复杂度

- 时间：`O(n)`
- 空间：`O(1)`

## 🔹 易错点

- 宽度是下标差 `right - left`。
- 应移动短板，而不是较高的一侧。
