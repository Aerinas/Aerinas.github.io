## 🔹 题目

给定柱状图高度，计算下雨后所有位置能够接住的雨水总量。

## 🔹 思路

- 维护左右指针，以及两侧已经见过的最高柱子 `leftMax`、`rightMax`。
- 较低一侧的接水量已经能由该侧最大值确定。
- 更新较低侧的最大值或累加水量，然后向中间移动。

## 🔹 C++17

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        if (n <= 2) return 0;

        int l = 0, r = n - 1;
        int leftMax = 0, rightMax = 0, ans = 0;

        while (l < r) {
            if (height[l] < height[r]) {
                if (height[l] >= leftMax) leftMax = height[l];
                else ans += leftMax - height[l];
                ++l;
            } else {
                if (height[r] >= rightMax) rightMax = height[r];
                else ans += rightMax - height[r];
                --r;
            }
        }
        return ans;
    }
};
```

## 🔹 复杂度

- 时间：`O(n)`
- 空间：`O(1)`

## 🔹 易错点

- 当前较低的一侧决定本轮可以结算哪边。
- 最大高度必须先更新，再计算当前位置水量。
