## 42. Trapping Rain Water (方法一：前缀/后缀最大值)

### 🔹 思路
对每个位置 i，接水量 = `min(maxLeft[i], maxRight[i]) - height[i]`。  
- `prefix[i]`：从左到 i 的最高高度  
- `suffix[i]`：从右到 i 的最高高度  
最后一遍累加贡献。

### 🔹 实现
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        if (n <= 2) return 0;

        vector<int> prefix(n), suffix(n);

        prefix[0] = height[0];
        for (int i = 1; i < n; ++i)
            prefix[i] = max(prefix[i - 1], height[i]);

        suffix[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; --i)
            suffix[i] = max(suffix[i + 1], height[i]);

        int ans = 0;
        for (int i = 0; i < n; ++i)
            ans += min(prefix[i], suffix[i]) - height[i];
        return ans;
    }
};
```
### 🔹 复杂度

时间：O(n)

空间：O(n)

### 🔹 特点

逻辑最直观，容易理解

需要额外 O(n) 空间


## 42. Trapping Rain Water (方法二：双指针)

### 🔹 思路
使用双指针 `l`、`r` 从两端向中间夹逼，并维护 `leftMax`、`rightMax`。  
- 若 `height[l] < height[r]`，左侧水量由 `leftMax` 决定；  
- 否则右侧水量由 `rightMax` 决定；  
更新对应最大值或累加水量。

### 🔹 实现
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        if (n <= 2) return 0;

        int l = 0, r = n - 1;
        int leftMax = 0, rightMax = 0, ans = 0;

        while (l < r) {
            if (height[l] < height[r]) {
                if (height[l] >= leftMax) leftMax = height[l];
                else ans += leftMax - height[l];
                ++l;
            } else {
                if (height[r] >= rightMax) rightMax = height[r];
                else ans += rightMax - height[r];
                --r;
            }
        }
        return ans;
    }
};
```

### 🔹 复杂度

时间：O(n)

空间：O(1)
