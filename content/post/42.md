## 42. Trapping Rain Water (方法一：前缀/后缀最大值)

### 🔹 核心思路（前缀/后缀最大值）
对每个位置 i，接水量 = `min(maxLeft[i], maxRight[i]) - height[i]`。  
- `prefix[i]`：从左到 i 的最高高度  
- `suffix[i]`：从右到 i 的最高高度  
最后一遍累加贡献。

### 🔹 C++17 实现
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        if (n <= 2) return 0;

        vector<int> prefix(n), suffix(n);

        prefix[0] = height[0];
        for (int i = 1; i < n; ++i)
            prefix[i] = max(prefix[i - 1], height[i]);

        suffix[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; --i)
            suffix[i] = max(suffix[i + 1], height[i]);

        int ans = 0;
        for (int i = 0; i < n; ++i)
            ans += min(prefix[i], suffix[i]) - height[i];
        return ans;
    }
};
```
### 🔹 复杂度

时间：O(n)

空间：O(n)

### 🔹 特点

逻辑最直观，容易理解

需要额外 O(n) 空间


## 42. Trapping Rain Water (方法二：双指针)

### 🔹 核心思路（双指针）
使用双指针 `l`、`r` 从两端向中间夹逼，并维护 `leftMax`、`rightMax`。  
- 若 `height[l] < height[r]`，左侧水量由 `leftMax` 决定；  
- 否则右侧水量由 `rightMax` 决定；  
更新对应最大值或累加水量。

### 🔹 C++17 实现
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        if (n <= 2) return 0;

        int l = 0, r = n - 1;
        int leftMax = 0, rightMax = 0, ans = 0;

        while (l < r) {
            if (height[l] < height[r]) {
                if (height[l] >= leftMax) leftMax = height[l];
                else ans += leftMax - height[l];
                ++l;
            } else {
                if (height[r] >= rightMax) rightMax = height[r];
                else ans += rightMax - height[r];
                --r;
            }
        }
        return ans;
    }
};
```

### 🔹 复杂度

时间：O(n)

空间：O(1)

## 题目概括

给定每个位置的柱高，计算下雨后柱子之间能够存储的总水量。少于三个柱子时答案为 0。

## 算法步骤

1. 左右指针从两端向中间移动，并维护 `leftMax`、`rightMax`。
2. 较低一侧的可接水量已经由该侧最大值确定。
3. 更新对应最大值，或累加最大值与当前高度的差。
4. 指针相遇时得到总水量。

## 易错点

- 当前侧最大值不足时应先更新最大值，不能得到负水量。
- 双指针方案判断的是哪一侧上界已经确定。
- 空数组和长度不超过 2 的数组应返回 0。

## 模板总结

当每个位置的贡献由左右两侧界限的较小值决定时，可以预处理两侧最值，也可以用双指针逐步确定较小的一侧。
