## 1. Two Sum

### 🔹 题目描述
给定一个整数数组 `nums` 和一个目标值 `target`，请你在该数组中找出和为目标值的 **两个数的下标**。  
可以假设每种输入只会对应一个答案，但数组中同一个元素不能使用两遍。

### 🔹 解题思路
- 遍历数组，每次看当前数 `nums[i]` 所需的“补数”为 `target - nums[i]`。  
- 使用哈希表 `hashtable` 存储**已经遍历过的数值 → 下标**。  
- 在遍历过程中：
  - 如果补数已在哈希表中，说明找到了配对，返回两数下标。  
  - 否则，把当前数和下标加入哈希表，继续扫描。

### 🔹 关键点
- **哈希表**实现 O(1) 平均时间查找，整体复杂度降到 O(n)。  
- 插入顺序保证了不会用到同一个元素两次：  
  - 先查找补数 → 如果存在说明之前的某个数能配对。  
  - 若不存在，再把当前数存入哈希表。  

### 🔹 C++ 实现要点
- 容器：`std::unordered_map<int,int>`，键是数值，值是下标。  
- 查找：`auto it = hashtable.find(target - nums[i]);`  
  - 存在 → 返回下标对 `{it->second, i}`。  
  - 不存在 → 插入 `hashtable[nums[i]] = i;`  
- 返回空向量 `{}` 表示未找到（题目保证一定有解，所以正常不会走到这里）。

### 🔹 复杂度分析
- **时间复杂度**：O(n)，每个元素最多查找 + 插入一次。  
- **空间复杂度**：O(n)，哈希表存储元素。

### 🔹 总结
- 本题利用 **哈希表查找补数**，将暴力的 O(n²) 双循环优化为 O(n)。  
- 核心技巧是 **边遍历边存储**，保证不会重复使用同一个元素。

## 算法步骤

1. 从左到右遍历数组。
2. 计算当前元素需要的补数 `target - nums[i]`。
3. 若补数已经在哈希表中，返回补数下标和当前下标。
4. 否则记录当前数值及其下标。

## C++17 实现

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> index;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            auto it = index.find(target - nums[i]);
            if (it != index.end()) return {it->second, i};
            index[nums[i]] = i;
        }
        return {};
    }
};
```

## 易错点

- 必须先查补数再插入当前元素，避免同一位置被使用两次。
- 哈希表保存下标而不是只保存元素是否存在。
- 防御性返回空数组不会影响题目保证有解的正常路径。

## 模板总结

需要寻找两个元素满足固定和时，可以边遍历边保存已见元素，并在 `O(1)` 平均时间内查询补数。
