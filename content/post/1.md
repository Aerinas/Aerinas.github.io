## 🔹 题目

在数组中找到两个和为 `target` 的元素，返回它们的下标；同一位置不能使用两次。

## 🔹 思路

- 遍历 `nums`，当前数需要的补数是 `target - nums[i]`。
- 哈希表记录已经出现的“数值 → 下标”。
- 先查补数、再插入当前数，避免使用同一元素两次。

## 🔹 C++17

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> index;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            auto it = index.find(target - nums[i]);
            if (it != index.end()) return {it->second, i};
            index[nums[i]] = i;
        }
        return {};
    }
};
```

## 🔹 复杂度

- 时间：`O(n)`
- 空间：`O(n)`

## 🔹 易错点

- 哈希表保存的是下标，不只是元素是否存在。
- 必须先查询补数，再记录当前元素。
