## 题目概括

给定数组和窗口大小 `k`，窗口从左向右移动，返回每个窗口中的最大值。

## 核心思路

双端队列保存仍可能成为最大值的元素下标，并让对应数值保持单调递减。队首始终是当前窗口最大值的位置。

## 算法步骤

1. 枚举右端点 `right`，先移除已经离开窗口的队首下标。
2. 从队尾删除所有不大于当前值的下标。
3. 将当前下标加入队尾。
4. 当窗口形成后，把队首对应值加入答案。

## C++17 实现

```cpp
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        vector<int> answer;
        if (nums.empty() || k <= 0) return answer;

        deque<int> window;
        for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
            while (!window.empty() && window.front() <= right - k) {
                window.pop_front();
            }
            while (!window.empty() && nums[window.back()] <= nums[right]) {
                window.pop_back();
            }
            window.push_back(right);

            if (right >= k - 1) answer.push_back(nums[window.front()]);
        }
        return answer;
    }
};
```

## 复杂度分析

- 时间复杂度：`O(n)`，每个下标至多入队、出队各一次。
- 空间复杂度：`O(k)`。

## 易错点

- 队列存下标而不是只存数值，才能判断元素是否过期。
- 过期条件是 `index <= right - k`。
- 使用 `<=` 删除队尾相等元素，可保留更新的下标。

## 模板总结

滑动区间中反复查询最值时，可用单调队列淘汰永远不可能成为答案的旧元素。
